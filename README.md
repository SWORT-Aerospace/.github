# SWORT-Aerospace/.github

Organization-wide files for [SWORT Aerospace](https://github.com/SWORT-Aerospace).

- `profile/README.md` is the page shown at github.com/SWORT-Aerospace.
- `profile/banner.svg` is its animated banner: CSS and SMIL only, fonts and
  images embedded, so it renders inside GitHub's image sandbox.
- `SECURITY.md` is the default security policy for every public repository that
  does not publish its own.
